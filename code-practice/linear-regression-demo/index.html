Lý thuyết OLS

Tổng quan về hồi quy tuyến tính và phương pháp bình phương tối thiểu (OLS).

📌 Mô hình hồi quy tuyến tính

Hồi quy tuyến tính mô tả mối quan hệ tuyến tính giữa biến phụ thuộc y và biến độc lập x:

y = β₀ + β₁·x + ε
  • β₀ — Hệ số chặn (intercept): giá trị y khi x = 0
  • β₁ — Hệ số góc (slope): mức thay đổi của y khi x tăng 1 đơn vị
  • ε — Sai số ngẫu nhiên (nhiễu)

🎯 Phương pháp OLS

OLS (Ordinary Least Squares) tìm β₀, β₁ tối thiểu hoá tổng bình phương phần dư:

min Σ(yᵢ − ŷᵢ)²

Nghiệm giải tích tường minh:

β₁ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²
β₀ = ȳ − β₁·x̄

📊 Chỉ số đánh giá

R² (Hệ số xác định)
R² = 1 − SS_res/SS_tot

R² ∈ [0,1]. Càng gần 1 mô hình càng khớp tốt.

MSE (Mean Squared Error)
MSE = (1/n)·Σ(yᵢ−ŷᵢ)²
MAE (Mean Absolute Error)
MAE = (1/n)·Σ|yᵢ−ŷᵢ|

⚠️ Giả định mô hình

  • ✅ Quan hệ tuyến tính giữa X và Y
  • ✅ Sai số có phân phối chuẩn
  • ✅ Phương sai sai số đồng nhất (homoscedasticity)
  • ✅ Các quan sát độc lập với nhau
  • ✅ Không có đa cộng tuyến (đối với hồi quy bội)

Underfitting (Bậc thấp)
Mô hình quá đơn giản, không học được pattern trong dữ liệu. Train error và Test error đều cao.

Good Fit (Bậc vừa)
Mô hình cân bằng bias–variance. Tổng quát hoá tốt trên dữ liệu mới.
🔥
Overfitting (Bậc cao)
Mô hình học thuộc nhiễu trong dữ liệu. Train error rất thấp nhưng Test error tăng cao.
💡 Cách phòng tránh Overfitting
  • 🔢 Giảm độ phức tạp mô hình
  • 📊 Thu thập thêm dữ liệu
  • 🎲 Data augmentation
  • 📐 Regularization (L1/L2)
  • 🛑 Early stopping
  • 🌳 Dropout (Neural Networks)
  • ✂️ Cross-validation
